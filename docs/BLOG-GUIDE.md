## Workflow for each daily run
1. Pick the topic, research facts that need sources, write the post as `status: draft`.
2. Build: `npm ci` (once) then `npx tsx src/build.tsx --preview` and `npx tsx src/build.tsx`; run `python3 qa.py` (0 broken links, 100% text).
3. Commit the draft on a branch `blog/<date>-<slug>` and push the branch (never push drafts to main).
4. Publish the preview so the owner can read it: upload `preview/post/<slug>/index.html`, `preview/blog/index.html`, `preview/assets/site.css`, `preview/assets/site.js` to the preview artifact (slug 50fcf685-9410-4c00-bd9e-271fc47662d5) and give the link.
5. Send the owner: title, target keyword, 3-line summary, preview link. Ask: approve or changes?
6. On "approve": set `status: published`, rebuild, qa, merge the branch into main, push main (Railway deploys in ~3 min), confirm https://www.ottawadeckpro.ca/post/<slug> loads, delete the branch.
7. On changes: edit, rebuild, republish the preview, ask again.
